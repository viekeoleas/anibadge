# Znachok Show

Редактор и прошивка для круглого дисплея Waveshare ESP32-P4 800×800.

Android-приложение импортирует PNG, JPEG, GIF и MP4, хранит редактируемый проект
локально и сразу показывает живое превью всего зацикленного шоу без сборки
пакета для платы. Для каждого клипа доступны масштаб, позиция, поворот и режимы
Fit/Fill. Для GIF сохраняются исходные задержки кадров и доступны trim, скорость
и повторы. Встроенные text-card и logo-card позволяют создавать текстовые
сообщения и композиции с логотипом без внешнего редактора. Ambient создаёт
зацикленный градиент со свечением и пульсацией, ticker — бегущую строку с
направлением и скоростью; оба типа рендерятся и показываются в 60 FPS.
После каждого клипа можно выбрать один из четырёх переходов — растворение,
световой круг, световую волну или глубину — и сразу проверить точный стык с
реальным следующим клипом. Последний клип переходит обратно к первому.
Готовые визуальные кадры и переходы кешируются локально. Изменение тайминга,
trim, скорости или повторов перестраивает только расписание; JPEG-кадры
перекодируются лишь после визуальных изменений. Кеш записывается покадрово,
поэтому прерванную подготовку не нужно начинать с нуля.

Публикация выполняется одной кнопкой по локальной Wi-Fi сети платы. Перед
загрузкой приложение подготавливает только отсутствующие или визуально
изменённые кадры. Внутренний формат пакета пользователю выбирать не требуется.
Кнопка «Очистить память значка» удаляет только загруженные медиа с платы;
прошивка, настройки и проекты на телефоне сохраняются.

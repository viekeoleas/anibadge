# Automotive loops for Znachok P4

Nine silent, seamless Toyota Remotion compositions designed for the 800x800 circular
display on the Waveshare ESP32-P4 board:

- `ToyotaPulseP4` - premium black/red kinetic identity;
- `ToyotaNightCircuitP4` - cyan/red night-drive circuit aesthetic.
- `ToyotaEyePortalP4` - Toyota emblem morphs into a looking cyber-eye, then
  blinks into a turbine eclipse and loops back without text.
- `ToyotaCelicaNightRunP4` - the distinctive headlights and front view of a
  2003 Celica T230 emerge in rain before the coupe launches into a neon run.
- `ToyotaKintsugiCoreP4` - a black ceramic planet cracks open with golden
  kintsugi seams, exposes a mechanical reactor, and heals itself.
- `ToyotaCelicaBlueprintP4` - a technical drawing of the 2003 Celica assembles
  into a red coupe, receives a scanning paint pass, and turns toward the viewer.
- `ToyotaCelicaLaserResurrectionP4` - the real photographed Celica is laser
  scanned into a dark 2.5D stage without redrawing its custom bodywork.
- `ToyotaPortalEngineP4` - a full-display Toyota mark mutates from a chrome
  monolith into fractured scanlines, a nested-logo tunnel, and an energy core.
- `ToyotaPerspectiveTempleP4` - one continuous flight through a monumental red
  hall whose separated structures align into a full-display Toyota mark.

The Pulse and Circuit compositions are 6 seconds; five narrative compositions
are 8 seconds; Portal Engine and Perspective Temple are 10 seconds. All run at
30 FPS. The visuals use flat graphics and
controlled gradients to keep the JPEG frames generated by Znachok Show within
the ESP32-P4 media budget.

## Preview

```powershell
npm run dev
```

## Render

```powershell
npm run render:pulse
npm run render:circuit
npm run render:eye
npm run render:celica-night
npm run render:kintsugi
npm run render:celica-blueprint
npm run render:celica-laser
npm run render:portal-engine
npm run render:perspective-temple
```

The MP4 files are written to `out/` and can be imported into the Android
Znachok Show editor. Audio is intentionally omitted because the badge player
does not use it.

## BMW 10-second loops

Three silent, seamless 800x800 compositions run for 10 seconds at 30 FPS:

- `BmwJoyShiftP4` - a full-frame BMW roundel becomes an expressive face,
  looks around, enters a speed portal, and resolves through a kinetic JOY mark;
- `BmwMVelocityP4` - M colors launch into a headlight stare, neon road rush,
  and pulsing performance core;
- `BmwOrbitP4` - the roundel becomes a planet, orbital system, future city,
  and horizon radar.

```powershell
npm run render:bmw-joy
npm run render:bmw-m
npm run render:bmw-orbit

# Render all three
npm run render:bmw
```

The BMW MP4 files are written to `out/bmw-*.mp4`.
